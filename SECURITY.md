# Segurança

## Como reportar uma vulnerabilidade

Não abra issue pública para falha de segurança.

Use o **reporte privado de vulnerabilidade** do GitHub: aba **Security** deste repositório → **Report a vulnerability**. O relato fica visível só para os mantenedores.

Inclua, se puder:

- o componente afetado (serviço, endpoint, arquivo);
- os passos para reproduzir;
- o impacto que você enxerga;
- uma sugestão de correção, se tiver.

## O que esperar

Este é um projeto pessoal de estudo, mantido por uma pessoa. A resposta não tem prazo garantido, mas todo relato é lido, e a correção é registrada no histórico do repositório com crédito a quem reportou, se essa pessoa quiser.

## Escopo

Vale para o código deste repositório. Falhas em dependências de terceiros devem ser reportadas ao projeto de origem; o Dependabot deste repositório acompanha as correções publicadas.
